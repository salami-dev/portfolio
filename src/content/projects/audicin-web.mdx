## Scope

Audicin Web combined the public web product surface with backend implementation, infrastructure, and deployment operations.

## The hard part

The useful work was not only building screens or endpoints. It was keeping the interface, backend behavior, release path, and infrastructure model aligned enough that the product could be built and operated coherently.
